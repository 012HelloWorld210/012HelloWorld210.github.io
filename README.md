# 梁浩琪个人主页

GitHub Pages 站点：[www.leguanxiaoliang.com](https://www.leguanxiaoliang.com/)

首页使用原生 HTML、CSS 和 JavaScript，无前端构建依赖。`index.html` 提供中文静态内容，`assets/js/home.js` 负责中英文切换、移动导航和项目筛选；语言偏好存于 `preferredLanguage`。

本地预览：

```sh
python -m http.server 8765
```

访问 `http://localhost:8765/`。修改脚本后可用 `node --check assets/js/home.js` 检查语法。
